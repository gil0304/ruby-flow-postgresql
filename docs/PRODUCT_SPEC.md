# Ruby Flow — 製品仕様
コンセプト「Rubyの裏側を、Rubyで描く。」
対象：Ruby/Sinatra を学ぶ中高生・初学者・メンター。開発者向けデバッガへ拡張可能。
## MVP
投稿 CRUD アプリを実際に操作すると、ブラウザ→HTTP→app.rb→models.rb→PostgreSQL→ERB→HTML の流れが観測される。POST とリダイレクト後の GET は別リクエストとして表示し、必要なら親子リンクする。データの値・型・変換を確認できる。実際のファイル名、実行行、SQL種別、所要時間、ステータスを表示。ノード選択、履歴、再生/停止、前後ステップ、速度 0.5/1/2、リセット。空・エラー・切断・イベント欠落状態を明示。
## デモ
投稿一覧、作成、編集、削除、入力検証失敗。タイトルまたは本文の許可されたデモ値のみ可視化。DBは実際に永続化。HTML出力はエスケープ。削除は POST 等の状態変更用メソッドを使用。対象アプリと可視化は別タブ、最終的には並列表示を選べる。
## 非目標
任意アプリへの完全自動対応、全変数収集、全ERB式の自動追跡、分散トレース、公開サービス。ERB式は明示的に計測した式だけを表示し、未観測のものを推測しない。
