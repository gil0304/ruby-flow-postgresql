# UIデザイン
IDE と教育用図解の中間。派手なグラデーションや過剰なカードを避け、余白と細線を活かす。中央キャンバスを主役にする。
左：ファイルツリー / リクエスト一覧。中央：Browser 青、Ruby 赤、DB 緑、ERB 琥珀のノード。関連線とデータ粒子、方向矢印、実行中の枠。右：コード・行番号・変数・DB 表・HTMLのタブ。下：再生タイムライン、速度、前後、停止。実アプリは別タブリンク。
色だけで区別しない。選択状態、ラベル、形を併用。キーボード操作、フォーカス、縮小時のパネル折りたたみ、動き軽減設定。DOM側には読めるイベント一覧を設ける。日本語 UI、コードは等幅。空状態・切断・計測オフ・欠落・エラー・実測/補間を明確に表示。
